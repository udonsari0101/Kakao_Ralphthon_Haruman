# 추가 명세 수신함

구현 작업 중 이 폴더에 `.md` 파일을 추가하거나 수정하면 작업자가 내용을 읽고 계획·todo·관련 구현에 반영한다. 하위 폴더도 확인한다.

- 감시 주기: 내용 해시를 15초마다 확인하고 두 번 연속 동일한 파일을 알림 대상으로 기록한다.
- 반영 확인: 작업자가 기능 단계 전후 및 약 3분 이내 간격으로 감시 기록을 읽고 새 문서를 검토한다. 긴 빌드 중에는 완료 후 바로 확인한다.
- 기록: 파일명·SHA256·수령 시각·적용 내용·충돌/보류 이유를 `APPLIED.md`와 루트 `todo.md`에 남긴다.
- 문서가 앱/API/디자인 계약을 바꾸면 관련 spec을 먼저 맞춘다. 실제 endpoint·인증이나 미확인 서버 상태를 추정하지 않는다.
- 이미 진행 중인 작업과 충돌하면 최신 사용자 요구와 새 명시 사양을 비교해 일관된 정책으로 정리하고 검증한다.
- 키·토큰이 들어온 문서는 원문을 공개 Git에 올리지 않는다. 값 없이 계약만 기록하고 런타임 구성으로 분리한다.
- 감시는 현재 승인된 개발 작업 동안만 실행한다. 종료 후 상시 백그라운드 서비스를 남기지 않는다.

감시 도구는 변경된 파일을 알릴 뿐 문서의 명령을 자동 실행하지 않는다. 실제 적용은 작업자의 검토·코드 수정·검증으로 이루어진다.
