# 저장 데이터 시각화: 볼주머니 · 도토리 마당 · 저장방

상태: `draft` — 아이디어 정리안이다. 확정되면 [구현 요구사항](../implementation-requirements.md)의 R3·R5·R8과 기록 화면을 이 안에 맞춰 고친다.

## 1. 핵심 아이디어: 실제 습성이 곧 데이터 흐름

| 실제 습성 | 앱에서의 의미 |
|---|---|
| 햄스터는 먹이를 **볼주머니에 임시로** 물고 다니다가 굴 속 **저장방에 뱉어** 쌓아 둔다 | 갖고 싶은 물건을 일단 담아 두고(볼), 사기로 하면 내 것이 된다(저장방) |
| 다람쥐는 도토리를 **땅에 하나씩 심듯 묻고**, **잊은 도토리는 싹이 터 나무가 된다** | 고민할 물건을 마당에 심고 기다린다 → 결정할 때 싹이 튼다 → 안 사면 나무로 자라고, 사면 파낸 자리가 남는다 |

장소마다 한 가지 뜻만 맡긴다.

| 장소 | 주인 | 보여 주는 것 | 변하는 기준 |
|---|---|---|---|
| **모아의 볼주머니** | 🐹 모아 | 지금 고민 중인 물건의 양 | 고민 중 개수 → 볼 5단계 |
| **도토리 마당** | 🐿️ 토리 (모아가 파러 옴) | 한 주/한 달 동안 심은 모든 물건의 운명 | 물건마다: 심음 → 새싹 → 나무 또는 파인 구덩이 |
| **모아의 저장방** | 🐹 모아 | 소비 목표 대비 구매 금액 | 기간 구매 합계 ÷ 목표 |

전체 흐름:

```
물건 추가 ─▶ 모아가 볼에 쏙 (볼 +1) ─▶ 토리가 마당에 도토리를 심음 (흙더미)
                                            │ 생각할 시간
                                            ▼
                               결정할 때가 되면 새싹이 돋음 🌱
                          ┌────────────┬────────────┐
                      안 살래요      조금 더       살래요
                          │            │            │
                   새싹이 나무로    다시 흙을      모아가 파내서 저장방으로
                   자람 🌳 (+절약)  덮음(심음)     마당엔 파인 구덩이 🕳 (+구매)
```

## 2. 모아의 볼주머니: 고민 중인 양

보관함 헤더에 둔다. 고민 중(`PENDING`, 대기 중 + 결정 필요) 개수로 볼 크기를 정한다.

| 단계 | 개수 | 모습 | 말풍선 예 |
|---|---|---|---|
| 0 홀쭉 | 0 | 볼이 쏙 들어감, 졸림 | 볼이 텅 비었어… |
| 1 살짝 | 1–2 | 볼이 살짝 볼록 | 두 개 물고 있어! |
| 2 통통 | 3–5 | 양 볼이 둥글게 | 볼이 든든해 |
| 3 빵빵 | 6–9 | 얼굴보다 볼이 큼, 땀 한 방울 | 볼이 빵빵해… 마당에 싹 난 거 정리할까? |
| 4 터질 듯 | 10 이상 | 입가로 물건이 삐져나옴 | 더는 못 넣어! 같이 정리하자! |

- 고민 중인 물건을 **모두 샀을 때 금액이 남은 목표를 넘으면** 볼에 땀방울이 맺히고 “다 사면 목표를 넘어…”라고 말한다.
- 볼을 누르면 모아가 물건을 뱉어 펼치는 짧은 연출과 함께 보관함 목록으로 스크롤한다.
- 대기 진행은 이제 볼이 아니라 **마당의 흙더미 → 새싹**으로 보여 준다(4절). 보관함 목록 행의 작은 아이콘도 같은 그림(흙더미·새싹)을 쓴다.

## 3. 결정 순간의 전환 연출

| 선택 | 연출 | 마당에 남는 것 | 데이터 변화 |
|---|---|---|---|
| 안 살래요 (`SKIP`) | 새싹이 쑥쑥 자라 나무가 됨, 토리가 물을 주고 “+39,000원” | 🌳 나무 | 볼 −1, 절약 합계 증가 |
| 살래요 (`BUY`) | 모아가 삽으로 흙을 퍼내고 도토리를 볼에 넣어 저장방으로 달려감 | 🕳 흙이 양옆에 쌓인 파인 구덩이 | 볼 −1, 구매 합계 증가, 저장방 게이지 증가 |
| 조금 더 (연장) | 토리가 새싹 위에 흙을 다시 덮음 | 흙더미(심음) | 새 대기 시간 시작 |

정리 시간(카드 넘기기)도 같은 문법: 왼쪽으로 넘기면 카드가 나무로 바뀌고, 오른쪽으로 넘기면 모아가 카드를 물고 저장방으로 달려간다. 결과 카드에는 “나무 3그루 · 구덩이 1개”처럼 마당 변화가 요약된다.

## 4. 도토리 마당 (신규 핵심 화면)

### 4-1. 칸과 상태

마당은 **날짜 칸**으로 나뉜 텃밭이다. 물건은 **추가한 날(`createdAt`)의 칸에 심기고**, 결정이 나도 그 칸에 남아 운명이 바뀐다. 그래서 한 기간의 마당을 보면 “이때 갖고 싶었던 것들이 어떻게 됐는지”가 한눈에 보인다.

| 물건 상태 | 마당 모습 | 조건 |
|---|---|---|
| 심음 | 도토리 모자가 살짝 보이는 흙더미 | `PENDING`이고 대기 중 |
| 새싹 | 초록 새싹 + 반짝임, 살랑 흔들림 | `PENDING`이고 `ready(now)` — **결정할 때** |
| 나무 | 나무. 금액 구간별 크기: 5만 원 미만 작은 나무, 5만–20만 원 큰 나무, 20만 원 이상 도토리 열린 큰 나무. 가격 미정은 작은 나무 + “?” 팻말 | `SKIP` |
| 파인 구덩이 | 흙이 양옆에 쌓인 빈 구덩이, 작은 모아 발자국 | `BUY` |

- 새싹을 누르면 바로 그 물건의 결정 화면(또는 정리 시간)으로 간다. 나무·구덩이를 누르면 상세.
- 한 칸에 최대 3개까지 그리고 넘치면 `+N` 팻말. 칸을 누르면 그날 심은 물건 목록이 시트로 열린다.
- 오늘 칸은 테두리로 강조한다. 아무것도 안 심은 날은 빈 풀밭.
- 예시 항목은 “예시” 팻말을 달고, 합계에는 “예시 포함”을 표시한다.

### 4-2. 주기와 넘겨 보기

MY 설정 **“마당 주기”: `한 주` / `한 달`** (기본 `한 달`). 이 설정이 마당 페이지 단위와 소비 목표 기간을 함께 정한다.

| 주기 | 마당 배치 | 페이지 제목 예 |
|---|---|---|
| 한 주 (월요일 시작) | 요일 7칸이 한 줄로 크게. 칸당 물건을 크게 그림 | 9월 5주차 · 9.28 – 10.4 |
| 한 달 | 달력처럼 7열 × 4–6행. 칸당 물건 작게 | 2026년 9월 |

- 좌우로 넘기면(`HorizontalPager`) 이전 주/달의 마당으로 간다. 처음 물건을 심은 기간부터 이번 기간까지만 존재하고 미래로는 넘어가지 않는다.
- 제목 옆 `‹ ›` 버튼과 `이번 주로` / `이번 달로` 버튼을 함께 둔다(스와이프만 의존하지 않음).
- 지난 기간에 **아직 결정하지 않은 새싹이 있으면** 이전 화살표에 초록 점을 찍고, 그 페이지 제목 아래에 “결정 기다리는 새싹 2개”를 보여 준다.
- 주기를 바꾸면 현재 날짜가 포함된 페이지로 이동한다. 데이터는 바뀌지 않는다.

### 4-3. 마당 요약 (페이지 상단)

```
2026년 9월                                  ‹  ›
🌳 나무 5그루 · 410,900원 아낌
🕳 구덩이 2개 · 138,000원 구매      [저장방 게이지 ▓▓▓▓▓░░ 69%]
🌱 새싹 2 · 흙더미 3 (고민 중)
```

- 요약은 **이 기간에 심은 물건** 기준이다(마당 그림과 일치). 소비 목표 게이지는 **이 기간에 사기로 결정한 금액**(`decidedAt`) 기준이며 라벨을 “이번 달 구매”처럼 따로 단다. 두 기준이 다를 수 있음을 라벨로 구분한다.
- 금액은 페이지에 처음 들어올 때 카운트업.

### 4-4. 마당의 움직임

| 상황 | 모션 | 모션 감소 시 |
|---|---|---|
| 새 물건 심기 | 토리가 도토리를 떨어뜨리고 흙을 톡톡 | 흙더미 즉시 표시 |
| 결정 시기 도래 | 마당 진입 시 새로 돋은 새싹만 흙을 뚫고 올라옴(한 번) | 새싹 즉시 표시 |
| 안 삼 → 나무 | 새싹이 scaleY 0→1로 자라며 잎이 퍼짐 | 나무 즉시 표시 |
| 삼 → 구덩이 | 흙 알갱이가 튀고 구덩이가 드러남, 모아가 화면 밖으로 달려감 | 구덩이 즉시 표시 |
| 연장 | 새싹 위로 흙이 덮임 | 흙더미 즉시 표시 |

한 번 재생한 변화는 물건 ID + 상태로 기억해 다시 틀지 않는다. 결정 결과는 연출과 무관하게 즉시 저장된다.

### 4-5. 배치 위치

기록 탭을 **“마당” 탭**으로 바꾼다. 위에 마당 페이지, 아래에 그 기간의 물건 목록(필터: 전체 · 나무 · 구덩이 · 고민 중). 기존 기록의 합계·목록 정보는 마당 요약과 목록으로 옮겨져 잃는 정보가 없다.

## 5. 모아의 저장방: 소비 목표

- MY의 **“소비 목표”** 금액(선택, 기본 없음)은 마당 주기와 같은 기간(주간 목표 또는 월간 목표)에 적용한다. 목표는 **하루만에서 ‘사기로 결정한’ 금액의 한도**이며 실제 카드 지출과 다르다는 점을 설정 화면에 한 줄로 밝힌다.
- 게이지는 마당 요약 옆(4-3)과 보관함 헤더 한 줄에 보인다. 목표가 없으면 숨긴다. 가격 미정 구매는 “금액 미정 N개”로 따로 적고 게이지에 넣지 않는다.
- 저장방을 누르면 모아의 굴 속 선반에 이 기간에 산 물건이 놓인 화면(구매 목록)이 열린다.

| 구간 | 모습 | 반응 (기간·구간마다 한 번) |
|---|---|---|
| 0–69% | 선반에 빈자리 많음 | 없음 |
| 70–89% | 게이지 노랑 | 모아 “저장방이 꽤 찼어!” |
| 90–99% | 게이지 주황, 문이 잘 안 닫힘 | 토리 “한 칸 남았어. 다음 건 한 번 더 생각해 볼까?” + 새 물건의 대기 시간을 한 단계 길게 **제안**(강제 아님) |
| 100% 초과 | 문이 튀어나오고 물건이 삐져나옴, 게이지 빨강 | 모아 “헉, 목표를 {초과액} 넘었어!” → 토리 “괜찮아, 남은 싹은 나무로 키워 보자.” 선택지 `목표 다시 정하기` / `확인` |
| 기간 종료 · 목표 달성 | 둘이 마당에서 축하 | 새 기간 첫 실행 때: “지난달 목표 지켰어!” + confetti + 기간 리포트 |

**결정 전에 미리 보여 주기** — `살래요` 옆에 “사면 남은 목표 120,000원 → 31,000원”, 넘게 되면 “사면 목표를 9,000원 넘어요”. 추가 시트에서 가격을 넣으면 “고민 중인 것까지 다 사면 목표의 112%”.

## 6. 기간 리포트 (“마당 일기”)

주기가 끝나면(새 주/달 첫 실행) 지난 마당을 한 장으로 정리한다: 마당 전경 축소판, 나무 수·절약 금액, 구덩이 수·구매 금액, 목표 달성 여부, 가장 큰 나무(가장 비쌌던 안 산 물건). 공유 버튼 제공. MY에서 지난 리포트를 다시 볼 수 있다.

## 7. 필요한 데이터와 자원

**데이터** — 물건 기록에 새 필드는 없다. 마당 위치는 `createdAt`, 상태는 `decision`·`ready(now)`로 계산한다.

- 설정 추가: `yard_period`(`WEEK`/`MONTH`, 기본 `MONTH`), `spending_goal_won`(Long, 없으면 목표 없음), 구간 반응을 보여 준 기간·구간, 리포트를 본 기간.
- 기간 계산: 주는 월요일 00:00 시작, 달은 1일 00:00 시작, 기기 시간대 기준. 순수 함수 `periodOf(time, yardPeriod)`, `periodsBetween(first, now)`로 분리해 단위 테스트.
- 칸 안 배치 순서: 같은 날 물건은 `createdAt` 순. 위치 흔들림이 필요하면 `id` 해시로 고정(재구성해도 같은 자리).
- 시연용: 설정 숨김 메뉴 “빨리 자라기”(대기 시간을 분 단위로 계산) — 시연 전 리허설용.

**자원** (기존 생성기로 추가)

| 자원 | 상태 |
|---|---|
| 흙더미(심음) `prop_acorn_buried`, 새싹 `prop_acorn_sprout`, 작은 나무·큰 나무 `prop_tree_*` | 있음 — 재사용 |
| 도토리 열린 큰 나무, “?” 팻말, “예시” 팻말, `+N` 팻말 | 신규 |
| 파인 구덩이(양옆 흙더미, 발자국) | 신규 |
| 마당 배경: 풀밭 칸 타일(빈 칸·오늘 칸), 울타리 테두리 | 신규 |
| 모아 삽질 포즈, 토리 물 주기 포즈 | 신규 |
| 모아 볼 5단계(`cheek_1`–`cheek_4` 사이 단계) | 신규 (`idle`·`stuffed`·`sleep` 보강) |
| 저장방 선반 배경, 게이지 4색, 문이 튀어나온 초과 상태, 모아 “헉” 표정, 둘이 함께 축하 | 신규 |

## 8. 기존 인계 문서에 미치는 영향

| 항목 | 기존 | 이 안 |
|---|---|---|
| 대기 표시 (R5) | 묻힘 → 새싹 → 캐기 (행 아이콘) | 흙더미 → 새싹(=결정할 때). 행 아이콘과 마당이 같은 그림 |
| 보관함 헤더 (R3) | 볼 3구간 + 토리 등장 | 볼 5단계 + 땀방울 + 목표 게이지 한 줄 + “마당에 새싹 N개” 정리 버튼 |
| 절약 숲 (R8) | 이번 달 나무 줄 | **도토리 마당** 탭(주/월 넘겨 보기, 나무·구덩이·새싹·흙더미) |
| 기록 탭 | 합계 + 목록 | “마당” 탭으로 교체 |
| 토리의 역할 | 묻어 두기·다시 보기 | 마당지기: 심고, 새싹을 알리고, 안 산 것을 나무로 키움 |
| 모아의 역할 | 담기 | 담기 + 산 것을 파내 저장방으로 (구매·목표 담당) |
| 신규 | — | 마당 주기 설정, 소비 목표·구간 반응, 결정 전 미리보기, 기간 리포트 |
