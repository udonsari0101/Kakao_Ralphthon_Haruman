# 카피 덱: 상황별 캐릭터 대사

상태: `target` — 말풍선에 들어갈 문장 목록이다. 구현 시 `ui/mascot/MascotCopy.kt`의 상수로 옮기고, 한 상황에 여러 줄이 있으면 무작위로 하나를 고르되 **같은 화면 진입 동안에는 고정**한다(재구성마다 바뀌지 않게).

- `{name}` 상품명(12자 초과 시 말줄임), `{price}` `money()` 결과, `{n}` 개수, `{date}` `dateLabel()`, `{time}` `remaining()`/`cooldownLabel()` 결과.
- 가격이 `null`이면 `{price}`가 들어간 줄을 쓰지 않고 “가격 없음” 줄을 쓴다.
- 말풍선은 최대 2줄. 넘치면 첫 문장만 쓴다.
- 🐹 = 모아, 🐿️ = 토리.

## 온보딩

| 위치 | 화자 | 문장 |
|---|---|---|
| 제목(시스템) | — | 사고 싶은 마음,\n잠시 넣어두세요. *(기존 유지)* |
| 역할 소개 1 | 🐹 | 갖고 싶은 건 나한테 줘! 볼에 쏙 모아 둘게. |
| 역할 소개 2 | 🐿️ | 난 그걸 도토리처럼 묻어 뒀다가, 때가 되면 같이 꺼내 볼게. |

## 보관함 헤더 (모아의 방)

| 조건 | 포즈 | 문장 후보 |
|---|---|---|
| 보관 0개 | `MOA_SLEEP` | 볼이 텅 비었어… 갖고 싶은 거 생기면 깨워 줘. / 쿨쿨… 공유하기로 나를 불러 줘. |
| 보관 1–4개 | `MOA_IDLE` | 지금 {n}개 모아 뒀어! / 볼 안에 {n}개, 아직 여유 있어. |
| 보관 5개 이상 | `MOA_STUFFED` | 볼이 빵빵해… 토리랑 같이 정리해 볼까? / {n}개나 들어 있어! 조금 무거워… |
| 결정 필요 1개 이상 (토리 등장) | `TORI_PRESENT` 작은 크기 | 도토리 {n}개 캐 왔어. 같이 볼래? |
| CTA(시스템) | — | 정리 시간 시작 · {n}개 |

## 대기 중 상세

| 조건 | 포즈 | 문장 |
|---|---|---|
| 진행 0–49% (묻힘) | `TORI_BURY` | 잘 묻어 뒀어. {time} 뒤에 캐 올게. |
| 진행 50–99% (새싹) | `TORI_IDLE` | 싹이 났어! 조금만 더 기다려 보자. |
| 대기 끝 | `TORI_PRESENT` | 다 자랐어. 이제 꺼내 볼까? |

## 정리 시간 (카드 넘기기)

| 위치 | 화자 | 문장 |
|---|---|---|
| 카드 위 기본 | 🐿️ | {date}에 묻은 거야. 아직 갖고 싶어? |
| 저장 때 🔥였던 카드 | 🐿️ | 그땐 엄청 갖고 싶어 했지. 지금은 어때? |
| 저장 때 🤔였던 카드 | 🐿️ | 그때도 살짝 고민했었지? |
| ← 보내기(`SKIP`), 가격 있음 | 🐿️ | 잘 가~ {price} 아꼈어! |
| ← 보내기, 가격 없음 | 🐿️ | 잘 가~ 마음 한 번 더 확인했어. |
| → 사기로(`BUY`) | 🐹 | 충분히 고민했으니까 좋은 선택이야! |
| ↓ 조금 더(연장) | 🐿️ | 그럼 {time} 더 묻어 둘게. |
| 되돌리기 후 | 🐿️ | 다시 꺼내 왔어. 천천히 골라. |
| 스와이프 라벨(시스템) | — | 안 살래요 · 살래요 |

## 캐릭터 탭 반응 (P1)

- 🐹 헤헤, 간지러워! / 🐹 볼 만지지 마~ 다 쏟아져! / 🐹 오늘은 뭐 찾았어?
- 🐿️ 도토리 세는 중이야. / 🐿️ 묻은 곳은 다 기억하고 있어. / 🐿️ 숲이 조금씩 커지고 있어.

## 알림 (P2, 구현 시)

- 제목: 🐿️ 토리가 도토리를 캐 왔어요
- 본문: {date}에 담은 {name}, 아직 생각나?
- 여러 개: {n}개가 다시 볼 시간이 됐어. 같이 정리해 볼까?
