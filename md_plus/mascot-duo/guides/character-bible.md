# 캐릭터 설정: 모아와 토리

상태: `target` — 구현 전 캐릭터 기준이다. 이름·성격·말투를 바꿀 때는 이 문서와 [카피 덱](copy-deck.md)을 함께 고친다.

## 한 줄 콘셉트

> **모아가 담고, 토리가 묻어 두고, 때가 되면 같이 꺼내 본다.**

앱이 필요한 순간은 둘이다. *갖고 싶어진 순간*(빠르게 담기)과 *며칠 뒤 다시 보는 순간*(재미있게 정리하기). 두 캐릭터가 이 두 순간을 하나씩 맡는다. 사용자는 설명 없이도 “담는 친구 → 보관 → 꺼내 보는 친구” 흐름을 이해한다.

| | 🐹 모아 (햄스터) | 🐿️ 토리 (다람쥐) |
|---|---|---|
| 맡은 순간 | 담기: 공유·추가·보관함 | 다시 보기: 대기·정리 시간·결과·기록 |
| 습성 은유 | 볼주머니에 일단 넣고 본다 | 도토리를 묻어 두고 잊지 않고 캐 온다 |
| 성격 | 호들갑스럽고 욕심 많은 수집가. 뭐든 반긴다 | 차분하고 기억력 좋은 정리 담당. 기다릴 줄 안다 |
| 앱 데이터와 연결 | 보관 중(`PENDING`) 개수 → 볼 크기 | 대기 진행률 → 도토리 성장 단계, `SKIP` → 절약 숲 나무 |
| 대표 대사 | “받았다! 볼에 쏙 넣어 둘게!” | “이거 기억나? 아직도 갖고 싶어?” |

두 캐릭터는 한 팀이다. 모아가 받은 물건을 토리에게 건네면 토리가 도토리로 묻는다(저장 직후 연출). 정리 시간에는 토리가 캐 온 도토리를 보여 주고, 사기로 하면 모아가 기뻐하고 보내기로 하면 토리가 손을 흔든 뒤 나무를 심는다.

## 태도 원칙

- **어느 선택이든 칭찬한다.** 사기로 해도 “충분히 고민했으니 좋은 선택”, 보내도 “대신 나무가 자랐어”. 구매 결정을 실패로 표현하지 않는다.
- **비난·죄책감·절약 강요 금지.** “또 샀어?”, “참아야지”, “낭비” 같은 말은 쓰지 않는다.
- **가짜 숫자를 만들지 않는다.** 가격을 모르면 절약액을 말하지 않고 “마음을 한 번 더 확인했어”로 대신한다. 예시 상품은 실제 합계처럼 말하지 않는다.
- **구매 결정은 주문 완료가 아니다.** “샀어!”가 아니라 “사기로 했구나”라고 말한다.
- **방해하지 않는다.** 말풍선은 2줄 이내, 연출은 탭으로 넘길 수 있고 저장·결정 결과는 연출과 무관하게 즉시 반영된다.

## 말투 규칙

- 캐릭터 말풍선은 **다정한 반말**, 앱 시스템 문구(버튼·제목·안내)는 기존 **해요체**를 유지한다. 말풍선이라는 시각 구분이 있어 두 말투가 섞여 보이지 않는다.
- 모아: 느낌표·의성어가 많다(“쏙”, “빵빵”, “헤헤”). 짧고 들뜬 문장.
- 토리: 차분한 물음과 정리(“기억나?”, “그럼 다시 묻어 둘게”). 숫자를 정확히 말한다.
- 사용자 이름을 부르지 않는다(데이터가 없음). “우리”로 관계를 표현한다.

## 상태(포즈)와 자원 매핑

`assets/android-drawable/`의 파일명을 그대로 `R.drawable.*`로 쓴다. SVG 원본은 `assets/svg/`에 같은 이름으로 있다.

| 포즈 enum 제안 | 자원 | 쓰는 곳 |
|---|---|---|
| `MOA_IDLE` | `mascot_moa_idle` | 보관함 헤더(보관 1–4개), 기본 반응 |
| `MOA_RECEIVE` | `mascot_moa_receive` | 저장 직후 “받았다” 연출, 추가 시트 상단 |
| `MOA_STUFFED` | `mascot_moa_stuffed` | 보관함 헤더(보관 5개 이상) |
| `MOA_HAPPY` | `mascot_moa_happy` | 구매 결정 반응, 탭 반응 |
| `MOA_SLEEP` | `mascot_moa_sleep` | 보관함이 비었을 때, 빈 상태 |
| `TORI_IDLE` | `mascot_tori_idle` | 기록 화면, 절약 숲 옆 |
| `TORI_PRESENT` | `mascot_tori_present` | 정리 시간 카드 위, 결정 화면 |
| `TORI_BURY` | `mascot_tori_bury` | 대기 중 상세 화면, “조금 더 고민” 반응 |
| `TORI_WAVE` | `mascot_tori_wave` | 보내기(`SKIP`) 직후 반응 |
| `TORI_CHEER` | `mascot_tori_cheer` | 정리 결과 카드, 포기 결과 화면 축하 |

보조 자원: 도토리 성장 3단계(`prop_acorn_buried` → `prop_acorn_sprout` → `prop_acorn_ready`), 도토리 아이콘(`prop_acorn`), 절약 숲 나무(`prop_tree_small`, `prop_tree_big`), 담긴 물건(`prop_gift`), 온보딩 장면(`scene_duo_onboarding`).

## 그림 스타일

둥근 실루엣, 3–3.4 단위의 짙은 갈색 외곽선(`#5B3A22`), 단색 면과 옅은 하이라이트의 스티커풍. 캐릭터 색은 앱 테마(현재 파랑, 목표 빨강)와 무관하게 고정한다. 다크 모드에서도 면 색이 밝아 실루엣이 유지되며, 외곽선만 쓰는 장식선(Zz, 손짓 선, 톡톡 선)은 밝은 강조색으로 그렸다. 색 값은 [토큰·모션 명세](motion-and-tokens.md)에 있다.
