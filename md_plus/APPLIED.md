## 가이드와 기존 요구의 조정

- 신규 출처는 쿠팡/직접 입력을 유지한다. 가이드의 인스타그램 시연과 스크린샷 입력 언급은 과거 범위이므로 복원하지 않는다.
- 사용자 직접 요청에 따라 안내·캐릭터 말풍선 모두 친근한 해요체로 맞춘다. 모아의 들뜬 느낌과 토리의 차분한 역할은 유지한다.
- 빨강·라이트/다크/시스템, API 정상 자동 추가·부분 보완·저장 후 편집을 유지한다. 캐릭터 때문에 저장 탭이나 확인 단계를 더하지 않는다.
- 예시는 실제 절약 금액·숲·성과에서 제외하고 구분 표시한다. 새 설치에는 예시를 자동 생성하지 않는다.
- R1–R9를 필수 디자인 범위로 통합하고 P1은 필수 기능 검수와 함께 개선한다. P2 알림·결과 이미지 공유·배지는 확장 후보로 둔다.
- 제공 폴더의 외부 작업공간 문서 링크와 planning 스킬 지시는 이 저장소에 그대로 적용하지 않는다. 현재 GOAL_SPEC/todo/실제 소스를 기준으로 구현한다.

루트의 `HARUMAN_API_RESPONSE_SPEC.md`, `HARUMAN_PRODUCT_API_PLAN.md`는 개발 시작 전에 수령한 API 계약 초안으로 별도 설계에 반영한다. 이 표는 이후 `md_plus`에 추가·수정된 문서를 기록한다.
